📋 Số KH Chi nhánh & TH năm trước

Nhập để tính KH tăng ròng CN phân bổ xuống.
KH Chi nhánh (kỳ này)
TH Chi nhánh (31/12 n-1)
→ KH tăng ròng CN —

🏢 Thông số Phòng / Đơn vị

TH Phòng (31/12 n-1)
Tổng PC Phòng (PCđc CN)
PC Phòng này (PCđc P)
Hệ số H1 Phòng 0.5 / 0.8 / 1.0 / 1.2 / 1.5
→ KH Phòng (PP2) —

👤 Thông số Cán bộ (cho từng CT)

TH Cán bộ (31/12 n-1) Mặc định dùng TH từng CT
PC Cán bộ (Hvt riêng)
Tổng PCđc Phòng (Σ PC×H2)
Hệ số H2 cán bộ này 0.5 / 0.8 / 1.0 / 1.2 / 1.5
Công thức PP2:
KH(CB) = TH(CB) + KH_tăng_ròng(P) × PCđc(CB)/Σ PCđc(P)
KH_tăng_ròng(P) = KH(P) - TH(P)
PCđc(CB) = PC(CB) × H2
Tra hệ số H2:
NSLĐ ≥2× BQ → 0.5 1.2×÷2× BQ → 0.8 0.75×÷1.2× BQ → 1.0 <0.75× BQ → 1.2 <0.5× BQ → 1.5

📋 Hướng dẫn cài đặt
1
Mở Google Sheets mới → vào Extensions → Apps Script
2
Xóa code mặc định, dán toàn bộ nội dung file Code.gs đã tải về
3
Chạy hàm setupSheets() một lần để tạo các sheet (CB, VT, BSC, PB, PG, PG_ITEMS)
4
Nhấn Deploy → New deployment
• Type: Web App
• Execute as: Me
• Who has access: Anyone
5
Copy Web app URL → dán vào ô bên trái → Lưu & Kết nối
6
Vào Import Excel, import file BO_CHI_TIEU_KH.xlsx → tự động đồng bộ lên GSheet
⚠ Mỗi lần sửa code Apps Script cần Deploy lại (New deployment hoặc Manage deployments → Edit).
