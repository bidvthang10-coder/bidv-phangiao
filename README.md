# Phân Giao Chỉ Tiêu KPI & BSC — BIDV Chi nhánh Cẩm Phả

## Deploy lên Vercel

### Cách 1: Vercel CLI (nhanh nhất)
```bash
npm install -g vercel
vercel login
vercel --prod
```

### Cách 2: Kéo thả trên web (không cần lệnh)
1. Truy cập https://vercel.com/new
2. Chọn "Browse" → chọn thư mục này
3. Click Deploy

### Cách 3: Qua GitHub
1. Tạo repo GitHub mới, push thư mục này lên
2. Vào vercel.com → Import Git Repository
3. Chọn repo → Deploy

## Sau khi deploy
- Vào mục **🔗 Google Sheets** trong sidebar
- Dán URL Apps Script Web App
- Nhấn **Lưu & Kết nối**
